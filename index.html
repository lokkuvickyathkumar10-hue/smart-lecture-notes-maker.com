GETTING STARTED

How It Works

Three simple ways to turn learning into exam readiness.

Text-based notes

  1. Enter or paste lecture content.
  2. Select a note-making method.
  3. Generate organized notes.
  4. Edit and save your notes.
  5. Revise and download.

Voice-based notes

  1. Open Lecture Voice Recorder and allow microphone access.
  2. Start recording, pause/resume if needed, then stop.
  3. Upload/submit the audio for speech-to-text conversion.
  4. Review and edit the returned transcription.
  5. Choose a note format and generate notes.
  6. Save or download your notes.

Smart tests

  1. Select previously saved notes.
  2. Choose question count and type.
  3. Generate questions from the selected notes.
  4. Answer and submit the test.
  5. Review your score, correct answers and explanations.
Transparency & privacy

Typed notes and quiz generation run locally on the server using Python text-processing logic. Real audio transcription uses OpenAI's speech-to-text API and requires the administrator to configure an API key. No transcript is fabricated when transcription is unavailable. Short-answer scoring uses keyword overlap, not an AI judge. For public deployment, add authentication and private database/storage before using sensitive lecture recordings.
